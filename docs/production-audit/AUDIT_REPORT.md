# Production audit — 5 November 2026

**Decision: NOT READY.** Approval of legal/business content, isolated end-to-end testing, and verification of the actual hosting, backup and recovery configuration remain outstanding. No production data was changed.

## Architecture and scope

The active application is Next.js 16 App Router, React 19 and TypeScript. Prisma 6.19.3 uses the Neon driver adapter with PostgreSQL. Signed JWT cookies protect the administrative interface; server actions handle catalogue edits and enquiries. Attachments use a private Vercel Blob store. The legacy static Vite/HTML/JS implementation and `data/products.js` remain in the repository: the latter supplies the initial catalogue and development preview. `vinext`, Cloudflare Worker configuration and response-store tooling are an additional deployment path; the Vercel setup is not automatically proof that Worker deployment works. Styling is in `app/globals.css`; `app/sitemap.ts`, `app/robots.ts` and route metadata provide SEO. Six initial migration files were not assumed: there is one committed SQL migration and a lock file.

Live browser observation was limited to the homepage and the top of the catalogue at 375, 768, 1024 and 1440 CSS pixels; it is not a full responsive audit. At those widths, measured document scroll width did not exceed viewport width and loaded images reported no errors. The catalogue displayed 80 components across eight categories. At the time of the audit, the live footer displayed pending contact details; supplied phone, email and service area have since been added to the local branch but not deployed. No production form was submitted. Account permissions allowed listing the project but the Vercel detail request returned 404 and deployment history returned 403. Live settings, database, Blob configuration, field performance and authenticated workflows were not verified.
